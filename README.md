# Midea Android

TCL Android TV alkalmazás a Midea légkondicionáló külső
hőmérsékletének megjelenítésére.

## Célok

- Midea Cloud kapcsolat
- NetHome Plus bejelentkezés
- Külső hőmérséklet lekérdezése
- 5 másodperces frissítés
- TCL Android TV lebegő hőmérséklet-kijelzés
- Titkosított hitelesítőadat-tárolás

Target: Android 11 / API 30
Python: 3.11
Midea library: 0.10.7
